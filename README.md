## 📌 프로젝트 소개

**Campus Market**은 대학 구성원 간의 중고거래를 더욱 편리하게 만들기 위한 모바일 애플리케이션입니다.  
기존 중고거래 서비스와 달리, **학교 내 거래 환경**에 초점을 맞추어 다음과 같은 기능을 제공합니다.

- 교내 건물 및 거래 장소를 지도에서 확인
- 대면 거래 / 사물함 거래 / 택배 거래 방식 선택
- 사물함 위치를 직관적으로 확인할 수 있는 **2.5D 내부 뷰**
- 상품 등록 시 이미지 기반 상품 정보 처리
- 시간표 및 거래 가능 시간 비교를 통한 일정 조율

---

## ✨ 주요 기능

### 1. 회원 관리
- 회원가입 / 로그인
- 사용자 정보 관리

### 2. 상품 등록
- 상품 사진 업로드
- 카테고리 분류
- 상품 정보 요약
- 배경 제거 및 이미지 전처리

### 3. 거래 방식 선택
- 대면 거래
- 사물함 거래
- 택배 거래

### 4. 지도 기반 거래 지원
- 카카오 맵 API를 활용한 캠퍼스 지도 제공
- 건물 위치 및 거래 장소 마커 표시
- 건물 선택 시 내부 사물함 위치 확인 가능

### 5. 2.5D 사물함 거래 UI
- 건물 내부를 2.5D 형태로 시각화
- 사용자가 거래할 사물함 위치를 선택 가능
- 사물함 선택 시 하이라이트 및 애니메이션 효과 제공

### 6. 게시판 기능
- 게시글 작성 / 조회 / 수정 / 삭제
- 거래 상품 리스트 확인

### 7. 실시간 상호작용
- 사용자 간 채팅 기능
- 거래 일정 및 장소 조율
